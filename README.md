# Наши планы

Книга наших планов: тёмная записная книжка на пружине с перелистыванием страниц.

- галочка ставит на план штамп «исполнено» с датой;
- ＋ добавляет план, ✎ включает режим правки (нажать на план → изменить, переместить, удалить);
- ☁ подключает токен GitHub, после этого все изменения сами коммитятся в `data/plans.json`.

Токен: GitHub → Settings → Developer settings → Fine-grained tokens → репозиторий `Plans`, Contents: Read and write.
